## How to use a lesson

1. Read **In 3 lines** first. If that is all you need, stop there.
2. Read the rest once, slowly.
3. Take the **Quiz** without scrolling up.
4. Press **Mark as learned**. The [Review page](/review) will bring it back at 1, 3, 7, 16 and 35 days.
